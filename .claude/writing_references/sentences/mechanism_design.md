## [Optimal Design Goal] Optimal [mechanism] design is the synthesis of [rule A] and [rule B] that maximize [objective] while ensuring [constraint A] and [constraint B].

**Source**: Myerson (1981) and mechanism design literature
**Context**: Stating design objective

> Optimal auction design is the synthesis of allocation and payment rules that maximize seller revenue while ensuring incentive compatibility and individual rationality.

## [Revelation Principle] The revelation principle says that if a social choice function can be implemented with some [non-direct] mechanism, the same function can be implemented by an incentive-compatible mechanism with the same equilibrium outcome.

**Source**: Myerson (1979) - Revelation principle
**Context**: Stating foundational result

> The revelation principle says that if a social choice function can be implemented with some non-honest mechanism, the same function can be implemented by an incentive-compatible (honesty-promoting) mechanism with the same equilibrium outcome.

**Tags**: #revelation #principle #foundation #mechanism

## [Incentive Compatibility] Incentive compatibility ensures that [agents] have no incentive to misreport their true [private information]. Truthful reporting is a [equilibrium type] for each [agent].

**Source**: Mechanism design textbooks
**Context**: Defining incentive compatibility

> Incentive compatibility ensures that bidders have no incentive to misreport their true valuations. Truthful reporting is a dominant strategy for each bidder, and encourages bidders to reveal their true preferences.

**Tags**: #incentive #compatibility #truthful #mechanism

> The Myerson auction relies on the concept of virtual valuation, which is a function that maps each bidder's valuation to a virtual value representing the marginal revenue contribution.
